## Information
`What is it?` <br />
- Cryptic Transmitter is an open-source chat application that enables direct peer-to-peer communication using end-to-end AES-256 encryption for secure message transmission.

`Where can I use it?` <br />
- Cryptic Transmitter is suitable for secure private conversations, testing encrypted communication, educational purposes related to cryptography, or any scenario where direct, encrypted messaging without third-party servers is preferred.

`How can I use it?` <br />
- Generate your AES-256 key within the application, exchange it with the other party, and specify the target IP address and port. The software can automatically open the required port and establish a communication channel. Once connected, messages sent and received will be securely encrypted and displayed in real time.

## Installation

To install and use this software, simply extract the archive found in `Releases`.

Administrator privileges may be required for automatic port forwarding.

## Limitations

If your internet connection is behind CGNAT, direct connections using public IPv4 will not work. In that case, using a VPN or IPv6 is required to establish a connection.
